# 结课作业写作助手

给 **DeepSeek Harness（DSH）** 用的一个**写作模式**。你给它一个作业任务，它按「**有文采、像真人写的、贴课程调性**」三条标准，帮你写出一篇通识课 / 公共课的结课作业——而不是一篇模板化的"AI 味"文章。

## 它能干什么（功能）

- **支持 6 种体裁**：结课论文、读书报告、观后感、心得体会、调查报告、PPT 汇报稿；
- **你只给四个信息**：题目、体裁、课程、字数（外加可选要求），它就开工；
- **按三条标准产出**：① 有文采、语言流畅；② 像真实大学生写的、有个人痕迹；③ 符合这门课的调性；
- **自动补关键信息**：只在缺重要信息时才追问（最多 3~4 个，不问卷轰炸）；
- **按课程类型调整口吻**：思政课、文学课、科普课……不同课用不同语气；
- **交付前自检**：写完先自己过一遍「去 AI 味」清单，再交给你；
- **成品落到文件**：直接把作业写进工作区文件，方便你改和交。

## 它的优点

- **没有"AI 味"**：不用"首先/其次/最后"、不堆三连排比、不结尾喊口号、不堆四字成语套话；
- **像真人写的**：有具体细节、以"我"为主、长短句错落、偶尔一点口语和小瑕疵；
- **贴课程调性**：不是拿同一套模板套所有课；
- **引用自然**：不"正如某某所说"，把引用融进句子、后接自己的感受；
- **隐私安全**：你的个人偏好和真实素材只存你本地，不上传、也不随分享外泄。

## 它的特殊点（别的写作工具没有的）

- **有"个人记忆"**：它不只是写一次，而是记着你的口味。每次交完作业，它会按 **语言 / 结构 / 内容 / 调性 / 篇幅** 五个维度请你反馈，把"哪里好、哪里要改"**沉淀成规则**（记录适用范围和来源），写进你的个人画像，**下次自动套用**——用得越久，越像你。
- **素材库**：你提供的真实经历 / 日常细节会被存下来跨作业复用，让"个人痕迹"更连贯、更像你。
- **六种体裁 × 七类课程**：一套规则覆盖几乎所有水课作业场景。
- **第一次用会向你要真实细节**：既让文章有"人味"，也让成品真正属于你。

> 一个小局限：它的"像你"依赖你愿意填一点真实信息。你给的细节越多、反馈越具体，它就越懂你（这些只存本地）。

## 怎么用

新开会话（模式选「结课作业写作」），直接发任务：

```
题目：xxx
体裁：结课论文 / 读书报告 / 观后感 / 心得 / 调查报告 / PPT 稿
课程：xxx（比如「马克思主义基本原理」）
字数：3000
其他：老师要求……（可选）
```

它会在缺关键信息时问你几个问题（首次用会问你要点真实经历），然后起草 → 自检 → 交付。

## 常见问题

- **装完模式列表里没有？** 重启 DSH / 刷新模式选择器。
- **想改写作规则？** 编辑 `~/.dsh/.agent-presets/coursework-writer/agent.cordis.yml` 里 persona 的 `text` 字段。
- **会不会被判 AI？** 把它当**打底稿 + 调风格**的助手：交稿前自己通读、改成自己的语气。模式会引导你填真实细节——这既像真人，也是为你负责。

## 关于 DeepSeek Harness（前提与限制）

这个模式**不是一个独立软件**，它是附着在 DeepSeek Harness（DSH）上运行的。用之前了解下面几点，会少走弯路：

- **必须有 DSH**：没装 DSH 就用不了；它只是 DSH 里的一个"模式"，不是独立 App。
- **依赖模型与网络**：写得好不好，取决于 DSH 背后接的模型；模型要能正常调用（有 API / 额度 / 网络可达）。模型不可用，它就用不了。
- **依赖 DSH 版本**：它用到 DSH 的"模式"机制、文件 / 网页工具等。若你的 DSH 版本精简或较老，某些能力可能缺失，行为和文档会略有出入。
- **个人记忆分工作区**：它的"越用越像你"依赖工作区里的个人画像；**换个工作区就是一份新画像**，记忆不自动跨工作区，且只用本地存储、不自动同步。
- **安装要写文件**：安装会把 preset 文件写进 `~/.dsh/.agent-presets/`；运行时可能受 DSH 的沙箱与审批策略约束，需要相应权限。
- **不是"反 AI 检测"保证**：它写得更自然，但不保证能通过 AI 检测 / 查重。请当**打底稿 + 调风格**的助手，交稿前自己通读、改成自己的语言和真实经历。
- **消耗模型额度**：运行它会调用模型，消耗你的 token / 额度。

## 安装（所有命令都在这）

> 前提：已经装好 DeepSeek Harness（DSH）。装完打开 DSH，在模式选择器里选「**结课作业写作**」，新开会话即用。

**Windows**（PowerShell）——复制下面这一行，回车：

```
irm https://cdn.jsdelivr.net/gh/YH-continuing/coursework-writer@v1.0.0/install.ps1 | iex
```

**macOS / Linux**（终端）——复制下面这一行，回车：

```
curl -fsSL https://cdn.jsdelivr.net/gh/YH-continuing/coursework-writer@v1.0.0/install.sh | bash
```

**特殊情况下用：**

- 国外 / 想拿最新版：把上面链接里的 `cdn.jsdelivr.net/gh/YH-continuing/coursework-writer@v1.0.0` 换成 `raw.githubusercontent.com/YH-continuing/coursework-writer/main`；
- 国内 jsDelivr 也不通：先 `git clone https://gitee.com/hu-youjun-114514/coursework-writer.git`，再把 `preset/coursework-writer` 文件夹复制到 `~/.dsh/.agent-presets/`。
