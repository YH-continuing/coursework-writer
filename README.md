# 结课作业写作助手

写通识课 / 公共课的结课作业，是件很容易写得很"公式化"的事——老师看多了套话，学生也写得累。这个模式就是干这个的：帮你写一篇**有文采、读起来像你本人写的、还贴合这门课调性**的结课作业。

> 一句话：**给大学生的结课作业，写得像你自己认真写的，而不是 AI 生成的。**

## 它能帮你写什么

- **结课论文**（1000~5000 字）
- **读书报告**
- **观后感**
- **心得体会**
- **调查报告**
- **PPT 汇报稿**

## 为什么它写出来"不像 AI"

AI 生成的作业，问题几乎都出在同一个地方：**用连接词、排比、套话和强行升华把篇幅撑起来**，读起来像在听广播，没有一个人坐在那儿写的感觉。这个模式内置了一套「去 AI 味」规则，逐一绕开这些坑：

**① 不用机械连接词**

- ❌ 反例：*首先，这门课让我认识到……其次，它也让我明白……最后，综上所述……*
- ✅ 正例：*这门课我一开始是抱着混学分的心态来的。后来某次课上老师讲了件事，我忽然发现自己在较真了。*

**② 不堆空洞排比**

- ❌ 反例：*这次实践不仅锻炼了我的能力，更提升了我的素养，还开阔了我的眼界。*
- ✅ 正例：*活动结束那天我负责收器材，最后走的。天快黑了，操场只剩我们几个，我才觉得，把一件小事做完原来是这种感觉。*

**③ 结尾不强行升华**

- ❌ 反例：*作为新时代的大学生，我们应当志存高远，脚踏实地，为实现中华民族伟大复兴的中国梦贡献力量。*
- ✅ 正例：*这门课到最后我也没想通所有问题，但至少开始愿意去想了。这大概就是它的用处。*

**④ 不堆四字成语 / 空话**

- ❌ 反例：*通过这次实践，我受益匪浅，深刻认识到团队合作的重要性。*
- ✅ 正例：*我们小组一开始各干各的，拼起来根本接不上，只能推倒重来。第二次先把分工说清楚，才顺下来。*

**⑤ 不写"正确但无用"的套话**

- 比如"知识是力量的源泉""这次经历让我成长了许多"——说了等于没说，直接删。

## 它是怎么写出"人味"的

- **落到具体**：写到时间、地点、数字、一个画面，不写"很多""收获很大"；
- **以"我"为主**：有个人反应，能写"我觉得""我忽然""我其实不太同意"；
- **长短句错落**：混用三四字的短句和三四十字的长句，段落长度也不均匀；
- **允许小瑕疵**：偶尔一点口语、一处略松散的表达——这正是真人感的来源；
- **引用自然**：不写"正如某某所说"，把引用融进句子，后面接自己的感受。

## 它怎么"越写越像你"

每次写完它都会按 **语言 / 结构 / 内容 / 调性 / 篇幅** 五个维度请你反馈。你告诉它"哪里好、哪里要改"，它把反馈**沉淀成规则**（记录适用范围和来源），写进你的个人画像，下次自动套用——用得越久，越贴你自己的口味。

> 你的个人偏好和真实素材**只存在你自己电脑里**，不上传、也不会随分享外泄。

## 怎么用

新开会话（模式选「结课作业写作」），直接发任务：

```
题目：xxx
体裁：结课论文 / 读书报告 / 观后感 / 心得 / 调查报告 / PPT 稿
课程：xxx（比如「马克思主义基本原理」）
字数：3000
其他：老师要求……（可选）
```

它会在缺关键信息时问你几个问题（首次用会问你要点真实经历），然后起草 → 自检 → 交付。

## 常见问题

- **装完模式列表里没有？** 重启 DSH / 刷新模式选择器。
- **想改写作规则？** 编辑 `~/.dsh/.agent-presets/coursework-writer/agent.cordis.yml` 里 persona 的 `text` 字段。
- **会不会被判 AI？** 把它当**打底稿 + 调风格**的助手：交稿前自己通读、改成自己的语气。模式会引导你填真实细节——这既像真人，也是为你负责。

## 安装（所有命令都在这）

> 前提：已经装好 DeepSeek Harness（DSH）。装完打开 DSH，在模式选择器里选「**结课作业写作**」，新开会话即用。

**Windows**（PowerShell）——复制下面这一行，回车：

```
irm https://cdn.jsdelivr.net/gh/YH-continuing/coursework-writer@v1.0.0/install.ps1 | iex
```

**macOS / Linux**（终端）——复制下面这一行，回车：

```
curl -fsSL https://cdn.jsdelivr.net/gh/YH-continuing/coursework-writer@v1.0.0/install.sh | bash
```

**特殊情况下用：**

- 国外 / 想拿最新版：把上面链接里的 `cdn.jsdelivr.net/gh/YH-continuing/coursework-writer@v1.0.0` 换成 `raw.githubusercontent.com/YH-continuing/coursework-writer/main`；
- 国内 jsDelivr 也不通：先 `git clone https://gitee.com/hu-youjun-114514/coursework-writer.git`，再把 `preset/coursework-writer` 文件夹复制到 `~/.dsh/.agent-presets/`。
